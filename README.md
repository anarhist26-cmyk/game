# Blood Legends

Интерактивный макет интерфейса браузерной MMORPG во вселенной Blood Legends.

## Возможности

- Полноэкранная сцена без прокрутки с единым игровым окном и атмосферным освещением.
- Верхний HUD с ресурсами, славой и синхронным серверным временем.
- Плавающие оверлеи персонажа, квестов, инвентаря, чата и боевого центра, вписанные в единое пространство без колонок.
- Панель персонажа с динамическими полосами НР/МР/опыта и характеристиками героя.
- Переосмысленная карта-лабиринт с сеткой переходов, промежуточными шагами, секторами локаций и управлением клавишами/WASD.
- Легенда узлов, координатный индикатор, журнал маршрута и подсказки об угрозах секторa.
- Боевой центр с карточкой противника, действиями, статусами и трофеями, а также отдельный журнал боя.
- Общий чат с отправкой сообщений и быстрым просмотром истории.

## Запуск

Откройте `index.html` в любом современном браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

После запуска перейдите по адресу [http://localhost:8000](http://localhost:8000) и откройте страницу `index.html`.

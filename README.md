# Blood Legends

Интерактивный макет клиентского окна MMORPG Blood Legends в стилистике классических десктопных RPG.

## Возможности

- Окно клиента 1024×768 с рамкой, боковой колонкой портретов и футером, повторяющим атмосферу референса Dark Swords.
- Верхняя панель отображает логотип, полосы HP/MP/XP, характеристики героя и счётчики ресурсов с серверным временем.
- Центральная карта-лабиринт рисуется на canvas, включает сектора локаций, промежуточные шаги, точки встреч, координаты и стрелочное управление перемещением.
- Боковая разведпанель показывает активного противника, описание угрозы, доступные боевые действия и список полученного лута.
- Журнал и чат оформлены в общем окне: вкладки переключают боевые записи и коммуникацию, есть форма ввода команд и ряд системных кнопок.
- Боевой сценарий позволяет атаковать, защищаться, использовать умение или эликсир, а также генерирует награды и обновляет полосы здоровья/маны.
- Инвентарь открывается отдельным окном с сеткой предметов, таблицей экипировки (шлем, кулон, перчатки, кольца, оружие, пояс, обувь, поножи, щит/второе оружие, броня, плащ), подробностями и синхронизированными ресурсами героя.
- Кодекс открывается поверх клиента, содержит вкладки «Бестиарий», «Локации» и «Трофеи» и автоматически подхватывает данные из JSON-каталогов, показывая характеристики, способности, локации обитания, события в пути и источники добычи.
- В каталоге `data/` хранятся независимые таблицы лута, монстров и локаций; боевой интерфейс подтягивает актуальные данные из JSON, поэтому добавленные существа (например, `Скелет-воин`) и их характеристики/места обитания сразу отражаются в игре вместе с соответствующим лутом. При недоступности файлов клиент переключается на встроенный набор каталогов, сохраняя карту и встречи активными.

## Запуск

Откройте `index.html` в любом современном браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

После запуска перейдите по адресу [http://localhost:8000](http://localhost:8000) и откройте страницу `index.html`.

> ⚠️ Если открыть страницу напрямую через `file://`, браузер заблокирует загрузку JSON. В этом случае клиент использует встроенный резервный набор данных — карта и боевые столкновения остаются доступными, но изменения в файлах `data/*.json` не подхватываются. Чтобы редактирование каталогов отражалось в игре, используйте запуск через локальный сервер.

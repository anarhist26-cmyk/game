# Blood Legends

Интерактивный макет интерфейса браузерной MMORPG во вселенной Blood Legends.

## Возможности

- Панель персонажа с показателями НР, МР, опыта и характеристик.
- Список квестов с состояниями «Активен», «Доступен» и «Завершён».
- Карта мира Империи Кровавого Полумесяца с описанием локаций.
- Журнал боя, реагирующий на действия игрока.
- Панель действий (Атака, Защита, Умение, Лечение) с тематическими сообщениями.
- Карточка противника с полосой здоровья.
- Общий чат с возможностью отправки сообщений.
- Блок лора, автоматически обновляющийся дополнительными легендами.

## Запуск веб-макета

Откройте `index.html` в любом современном браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

После запуска перейдите по адресу [http://localhost:8000](http://localhost:8000) и откройте страницу `index.html`.

### Подготовка окружения

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Настройка окружения и доступа

1. Скопируйте файл `.env.example` в `.env`.
2. Заполните переменные `TELEGRAM_TOKEN`, `BNOVO_USERNAME` и `BNOVO_PASSWORD` — это токен телеграм-бота и ваши логин/пароль от Bnovo.
3. При необходимости укажите `BNOVO_BASE_URL`, если используется иной домен.
4. Опционально скорректируйте `APARTMENT_MAPPING_FILE`, `REPORT_TEMPLATE`, `REPORT_OUTPUT_DIR`, а также `BNOVO_LOGIN_ENDPOINT` и `BNOVO_BOOKING_ENDPOINT`, если в вашем аккаунте настроены альтернативные адреса API.

### База апартаментов

Файл `bot/data/apartments.json` содержит соответствия номеров апартаментов адресам. Формат:

```json
{
  "101": ["СТАРТ"],
  "202": ["Ладожский авенир", "Путилов авенир"]
}
```

* Ключ — номер апартаментов (строка). Значение — массив названий адресов из таблицы выше или ID отеля.
* Если номер встречается на нескольких адресах, перечислите все варианты. Бот предложит выбрать нужный дом с помощью кнопок.
* Для нестандартного расположения файла измените переменную `APARTMENT_MAPPING_FILE` в `.env`.

### Запуск и использование

```bash
python -m bot
```

1. В Telegram откройте чат с ботом и отправьте `/start`.
2. Введите номер апартаментов. При дублировании на разных адресах бот пришлёт кнопки с вариантами.
3. После выбора адреса отправьте `/report`. Бот построит отчёт с 1-го по последнее число прошедшего месяца и пришлёт XLSX-файл. Копия сохраняется в каталоге `REPORT_OUTPUT_DIR`.

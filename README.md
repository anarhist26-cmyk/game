# Blood Legends

Интерактивный макет интерфейса браузерной MMORPG во вселенной Blood Legends.

## Возможности

- Заголовок с ресурсами, счётчиком славы и синхронным серверным временем.
- Тематический визуальный стиль с голографическими панелями и подсвеченными состояниями элементов.
- Панель персонажа с показателями НР, МР, опыта и характеристик.
- Динамический бой с живыми полосами ресурсов, умениями, щитами и сменой противников арены.
- Список квестов с фильтрами по состоянию и визуальными статусами.
- Переосмысленная карта-лабиринт в отдельном окне с секторами локаций, сеткой коридоров, промежуточными шагами между целями и управлением WASD/стрелками.
- Подсветка посещённых путей, легенда узлов, координатный индикатор и глифы испытаний отражают уровень угрозы и награды каждой точки.
- Боевой центр с выровненными панелями объединяет карточку противника, действия, статусы и трофеи с синхронизированными индикаторами.
- Отдельное окно журнала боя выводит хронологию схваток и критические события.
- Общий чат с возможностью отправки сообщений.
- Инвентарь героя, список участников гильдии и таблица арены.
- Таймеры мировых событий и блок лора с автообновлением легенд и эффектами усиленной атмосферы.

## Запуск

Откройте `index.html` в любом современном браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

После запуска перейдите по адресу [http://localhost:8000](http://localhost:8000) и откройте страницу `index.html`.

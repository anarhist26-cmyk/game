# Blood Legends

Интерактивный макет интерфейса браузерной MMORPG во вселенной Blood Legends.

## Возможности

- Панель персонажа с показателями НР, МР, опыта и характеристик.
- Список квестов с состояниями «Активен», «Доступен» и «Завершён».
- Карта мира Империи Кровавого Полумесяца с описанием локаций.
- Журнал боя, реагирующий на действия игрока.
- Панель действий (Атака, Защита, Умение, Лечение) с тематическими сообщениями.
- Карточка противника с полосой здоровья.
- Общий чат с возможностью отправки сообщений.
- Блок лора, автоматически обновляющийся дополнительными легендами.

## Запуск

Откройте `index.html` в любом современном браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

После запуска перейдите по адресу [http://localhost:8000](http://localhost:8000) и откройте страницу `index.html`.
